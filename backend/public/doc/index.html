📋 项目简介

飞鱼 Admin（feiyuadmin）是一套基于 Vue3 + ThinkPHP8 开发的通用型后台管理框架，支持 RBAC 权限控制、AI 智能助手、低代码平台、可视化工作流引擎等功能，适合快速搭建企业级管理后台。

✅ 完全免费开源 · MIT 协议 · 可商用 · 无任何加密授权

源码地址：https://gitee.com/gynet/feiyuadmin

项目版本

版本前端后端PHP说明
v1.0Vue2ThinkPHP6≥7.2基础框架
v2.0Vue3ThinkPHP8≥7.4重构升级
v3.0Vue3.5 + Vite5ThinkPHP8.1≥8.0AI集成+低代码+工作流

技术亮点

  • 🔥 Vue3 Composition API + Pinia，现代化开发体验
  • ⚡ Vite 5 热更新，开发效率提升 5 倍
  • 🔐 完整 RBAC 权限模型，支持数据权限
  • 🤖 AI 助手集成（文心一言 / 通义千问 / OpenAI）
  • 🧩 低代码平台：拖拽式表单设计，24+ 组件
  • 🔄 可视化工作流引擎：审批流 / 条件分支 / 节点配置
  • 📊 数据大屏：ECharts 可视化，拖拽式图表设计
  • 💳 支付集成：微信 / 支付宝多渠道

🔐 认证授权

系统采用 JWT（JSON Web Token） 无状态认证方式，登录成功后 Token 通过响应 body 返回，客户端自行存储，后续请求在 Header 中携带。

请求认证

所有需认证的 API 请求，需在 Header 中携带 Token：

Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...

登录响应格式

{ "code": 0, "msg": "登录成功", "data": { "token": "eyJhbGciOiJIUzI1NiJ9...", "expire_time": 1712500000, "user_info": { "id": 1, "username": "admin", "nickname": "管理员", "avatar": "/uploads/avatar/1.jpg", "roles": ["admin"], "permissions": ["*"] } } }

Token 刷新机制

  • Token 有效期默认 2 小时（7200 秒），可在 .env 中修改 JWT_EXPIRE
  • Token 过期后需重新登录获取新 Token
  • 建议客户端在 Token 过期前主动刷新（剩余 10 分钟时）

权限层级

层级说明
超级管理员roles=["admin"]，拥有所有权限，permissions=["*"]
角色权限通过 RBAC 模型关联菜单权限，控制哪些菜单可见
数据权限可按部门/岗位限制数据可见范围

📮 请求规范

Base URL

环境Base URL
后台管理/adminapi/
PC前台/pcapi/
移动端/mobileapi/

Content-Type

所有请求统一使用 Content-Type: application/json，请求体为 JSON 格式。

分页参数

参数类型说明
pageint页码（默认 1）
page_sizeint每页条数（默认 20，最大 100）

通用查询参数

参数说明
keyword关键字搜索（模糊匹配）
start_time开始时间（Y-m-d H:i:s）
end_time结束时间（Y-m-d H:i:s）
status状态筛选（int）
order排序字段
sort排序方式（asc/desc）

请求示例

POST /adminapi/system/user/lists HTTP/1.1 Host: demo.fydev.cn Content-Type: application/json Authorization: Bearer eyJhbGciOiJIUzI1NiJ9... { "page": 1, "page_size": 20, "keyword": "张三", "status": 1 }

📬 响应格式

成功响应

{ "code": 0, "msg": "操作成功", "data": { "list": [...], "total": 100, "page": 1, "page_size": 20 } }

错误响应

code说明
0成功
401未登录或 Token 过期
403无权限访问
404资源不存在
422参数验证失败
500服务器内部错误

server { listen 80; server_name demo.fydev.cn; root /www/wwwroot/feiyuadmin/backend/public; index index.html index.php; # 后台静态资源（Vue SPA） location /admin/ { try_files $uri $uri/ /admin/index.html; } # PC前台静态资源 location /pc/ { try_files $uri $uri/ /pc/index.html; } # 技术文档 location /doc { try_files $uri $uri/ /doc/index.html; } # 后端 API location /adminapi/ { try_files $uri $uri/ /index.php?s=$uri; } # 移动端 API location /mobileapi/ { try_files $uri $uri/ /index.php?s=$uri; } # PC前台 API location /pcapi/ { try_files $uri $uri/ /index.php?s=$uri; } # PHP-FPM location ~ \.php$ { fastcgi_pass 127.0.0.1:9000; fastcgi_index index.php; fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name; include fastcgi_params; fastcgi_read_timeout 300; fastcgi_buffer_size 64k; fastcgi_buffers 16 64k; } # 静态资源缓存 location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ { expires 30d; add_header Cache-Control "public, immutable"; } # ThinkPHP 伪静态 location / { if (!-e $request_filename) { rewrite ^(.*)$ /index.php?s=$1 last; break; } } # 安全头 add_header X-Frame-Options "SAMEORIGIN"; add_header X-Content-Type-Options "nosniff"; add_header X-XSS-Protection "1; mode=block"; }

❓ 常见问题（FAQ）

Q1：提示 "Class not found" 错误？

运行 composer dump-autoload 重建自动加载，并清除 runtime 缓存：php think clear

Q2：AI 对话返回 401 / 429 错误？

检查 .env 中 AI 配置是否正确，API Key 是否有余额。429 = 余额不足，401 = Key 无效。可在前端页面右上角"API配置"填入有效 Key 测试。

Q3：文件上传失败？

检查 backend/runtime/ 和 backend/public/uploads/ 目录是否有写入权限：chmod -R 777 runtime/ public/uploads/

Q4：登录一直失败，验证码报错？

检查 Redis 是否正常运行，验证码依赖 Redis 存储 key。也可在 .env 中设置 CAPTCHA_DRIVER=none 临时关闭验证码。

Q5：如何获取百度文心一言 AK/SK？

访问 百度智能云控制台 → 搜索「文心千帆」→ 创建应用，即可获取 AK 和 SK。

Q6：如何获取通义千问 API Key？

访问 阿里云 DashScope 控制台 → 开通服务 → API-KEY 管理，即可获取。

Q7：工作流设计器无法保存？

检查数据库表 sys_workflow_design 是否存在，字段是否完整。运行 php think migrate:run 执行数据库迁移。

Q8：如何二开新增模块？

步骤：① 后端创建 Controller → ② 定义路由 → ③ 前端 views 新建页面组件 → ④ 在 router/index.js 注册路由 → ⑤ 在 sys_menu 表添加菜单记录（ pid=0 为顶级）

Q9：权限菜单不显示？

检查 sys_menu 表的 status 字段是否为 1，以及该角色的菜单权限是否关联了对应记录。

Q10：如何关闭注册功能？

在 .env 中设置 REGISTER_ENABLED=false，或在前端 router 中移除注册路由。
