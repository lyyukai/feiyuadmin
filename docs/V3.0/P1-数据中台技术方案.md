## 1. 背景与目标

当前 feiyuadmin 后台管理系统缺乏统一的数据同步与 ETL 编排能力。随着业务数据源增多（MySQL、Redis、API 接口、第三方系统），数据孤岛问题日益突出。

本模块目标：
- 构建**异构数据源之间的实时/离线同步**能力
- 提供**可视化 ETL 编排**与任务调度
- 统一管理数据同步任务，降低开发运维成本

---

## 2. 技术选型

### 2.1 DataX — 数据同步引擎

| 维度 | 说明 |
|------|------|
| 开发方 | 阿里巴巴开源，成熟度高 |
| 支持场景 | 离线批量数据同步（结构化 → 结构化） |
| 支持源端 | MySQL、Oracle、SQLServer、PostgreSQL、MongoDB、Redis、HDFS、FTP、HTTP 等 20+ |
| 原理 | Reader（读） → Channel（传输） → Writer（写），Job 模式单进程，TaskGroup 多线程并发 |
| 优势 | 稳定、跨库、配置简单、京东/阿里大规模验证 |
| 局限 | 无实时流（需配合 Canal）、无调度能力 |

**适用场景：** `feiyuadmin` 系统中 Oracle/MySQL → MySQL 的数据汇聚、报表库同步、历史数据归档。

### 2.2 DolphinScheduler — ETL 编排与任务调度

| 维度 | 说明 |
|------|------|
| 开发方 | Apache 顶级项目，原 Apache Incubator 项目（国产） |
| 定位 | 分布式可视化 DAG 任务调度系统 |
| 核心能力 | DAG 可视化编排、任务依赖管理、定时调度、失败重试、告警通知、多租户 |
| 部署方式 | Standalone（单机）、Cluster（分布式） |
| 生态 | 支持 Shell、Python、Spark、Flink、DataX、SQL、API 等 30+ 任务类型 |
| 优势 | 国产、中文友好、界面直观、K8s 原生支持 |

**适用场景：** DataX 同步任务的定时调度、跨工作流依赖、告警通知。

## 4. 功能设计

### 4.1 数据源管理（FeiyuAdmin 内置）

在 `feiyuadmin` 后台新增「数据源管理」菜单：

| 功能 | 说明 |
|------|------|
| 数据源配置 | 配置源端/目标端连接（MySQL、Oracle、SQLServer、PostgreSQL、Redis、MongoDB、HDFS 等） |
| 连接测试 | 一键测试数据源连通性 |
| 数据预览 | 查看源端表结构和数据样本 |
| 敏感信息加密 | 密码加密存储 |

### 4.2 同步任务管理

| 功能 | 说明 |
|------|------|
| 任务创建 | 选择源端 → 选择目标端 → 配置字段映射 |
| 同步模式 | 全量同步（一次性）/ 增量同步（基于时间戳或 ID） |
| 限速配置 | 防止生产环境数据库被抽压垮 |
| 并发控制 | Channel 数量、Task 并发数 |
| 任务模板 | 常用场景保存为模板 |

### 4.3 任务调度（DolphinScheduler 集成）

| 功能 | 说明 |
|------|------|
| 定时配置 | Cron 表达式，支持分钟/小时/天/周/月 |
| 依赖触发 | 上游任务完成后触发下游（如：数据清洗 → 数据同步 → 报表生成） |
| 失败重试 | 自动重试次数和间隔可配置 |
| 告警策略 | 失败告警、超时告警 |

### 4.4 执行监控

| 功能 | 说明 |
|------|------|
| 执行日志 | 实时查看 DataX 日志 |
| 执行历史 | 历史执行记录、耗时、数据量统计 |
| 数据统计 | 同步行数、错误行数、速率 |
| 告警通知 | 钉钉机器人 / 企业微信 / 邮件通知 |

## 5. 部署方案

### 5.1 部署架构

**推荐模式：All-in-One（初期）+ 分布式扩展（后期）**

```
服务器规划（初期，2台）：
  服务器A（主控）：
    - feiyuadmin 后台（当前 39.105.173.6:8088）
    - DolphinScheduler Master
    - DolphinScheduler Worker
    - DataX Executor
  
  服务器B（数据节点）：
    - DolphinScheduler Worker
    - DataX Executor
    - Prometheus（监控）
```

### 5.2 DolphinScheduler 部署

```yaml
# docker-compose.yml（节选）
dolphinscheduler:
  image: apache/dolphinscheduler:latest
  container_name: feiyu_dolphinscheduler
  environment:
    - DATABASE_TYPE=mysql
    - SPRING_DATASOURCE_URL=jdbc:mysql://mysql:3306/dolphinscheduler
    - SPRING_DATASOURCE_USERNAME=feiyu
    - SPRING_DATASOURCE_PASSWORD=feiyu123456
  ports:
    - "12345:12345"   # API 端口
    - "5678:5678"      # UI 端口
```

### 5.3 DataX 部署

```bash
# 在 DolphinScheduler Worker 宿主机部署 DataX
cd /opt && wget https://github.com/alibaba/DataX/releases/download/v202309/datax.tar.gz
tar -xzf datax.tar.gz

# Python3 环境（DataX 依赖）
apt install python3 && ln -sf /usr/bin/python3 /usr/bin/python
```

## 6. 与现有系统集成

### 6.1 FeiyuAdmin 接口扩展

在 `feiyuadmin` 后端新增 API：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/datasource/lists` | GET | 数据源列表 |
| `/api/datasource/add` | POST | 新增数据源 |
| `/api/datasource/test` | POST | 测试连接 |

| `/api/sync/task/start` | POST | 手动触发执行 |
| `/api/sync/logs` | GET | 执行日志 |

### 6.2 认证集成

DolphinScheduler 支持 SSO（CAS/OIDC），可与 Keycloak（见 SSO 模块）统一认证，实现 Single Sign-On。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 增量同步时间戳方案不通用 | 中 | 支持自定义 SQL 条件 + 可视化配置 |
| 大表同步超时 | 高 | 分片并发（DataX 支持），同时限速 |
| 源端数据库权限不足 | 中 | 提供最小权限清单脚本 |
| DolphinScheduler 资源占用 | 中 | Worker 容器资源限制（CGroup） |
