**模块负责人：** 王坚（运维专员）
**评审时间：** 预计周五评审
**版本：** V3.0 P1

---

## 1. 背景与目标

V3.0 系统架构复杂度提升，后端 PHP（ThinkPHP）、前端 Vue3、数据库 MySQL、缓存 Redis 等组件数量增多，**缺乏统一的监控和告警能力**，运维团队无法及时发现系统异常。

**本模块目标：**
- 构建**全覆盖监控体系**：基础设施 + 中间件 + 应用层
- 提供**可视化大盘**：系统运行状态一目了然
- 实现**分级告警**：问题分级，通知到人，响应闭环

## 2. 技术选型

### 2.1 Prometheus — 指标采集与存储

| 维度 | 说明 |
|------|------|
| 开发方 | CNCF 毕业项目，SoundCloud 开源 |
| 定位 | 云原生监控系统的事实标准 |
| 数据模型 | 时序数据库（Time Series），支持多维标签（Label） |
| 采集方式 | Pull 模式（Prometheus 主动拉取）、Push Gateway（Push 场景） |
| 查询语言 | PromQL，强大灵活 |
| 优势 | 云原生、部署简单、图表丰富、社区生态庞大 |
| 局限 | 非日志系统（用 ELK）；非链路追踪（用 Jaeger） |

**监控对象（feiyuadmin 场景）：**
- 服务器：CPU、内存、磁盘、网络
- MySQL：QPS、连接数、查询慢 SQL、InnoDB 缓冲池
- Redis：内存使用、命中率、命令统计
- Nginx：连接数、请求速率、状态码分布
- PHP-FPM：进程数、请求队列、慢请求
- 应用层：API 响应时间、错误率

### 2.2 Grafana — 可视化大屏

| 维度 | 说明 |
|------|------|
| 开发方 | Grafana Labs 开源 |
| 定位 | 通用可视化平台（监控 + 日志 + APM + 追踪） |
| 数据源支持 | Prometheus、Elasticsearch、MySQL、PostgreSQL 等 30+ |
| 面板类型 | Graph、Stat、Gauge、Table、Heatmap、Geo Map 等 |
| 告警 | 原生告警引擎，支持邮件/钉钉/企微/PagerDuty |
| 优势 | 图表美观、Dashboard 社区共享、模板丰富 |

### 2.3 Alertmanager — 告警管理

| 维度 | 说明 |
|------|------|
| 开发方 | Prometheus 官方组件 |
| 功能 | 告警收敛、分组、去重、静默、路由、发送 |
| 通知渠道 | 邮件、钉钉、企业微信、PagerDuty、Slack、webhook |
| 优势 | 避免告警风暴，支持告警升级 |

## 4. 功能设计

### 4.1 监控指标体系

#### 4.1.1 基础设施监控

| 指标 | 采集器 | 告警阈值（示例） |
|------|--------|-----------------|
| CPU 使用率 | node_exporter | > 80% 警告，> 95% 严重 |
| 内存使用率 | node_exporter | > 85% 警告，> 95% 严重 |
| 磁盘使用率 | node_exporter | > 80% 警告，> 90% 严重 |
| 网络流入/流出 | node_exporter | > 1Gbps |
| 负载（Load Average） | node_exporter | > CPU 核数 × 0.7 |

#### 4.1.2 MySQL 监控

| 指标 | 采集器 | 告警阈值（示例） |
|------|--------|-----------------|
| QPS | mysqld_exporter | 突增 300% 警告 |
| 连接数使用率 | mysqld_exporter | > 80% 警告 |
| 慢查询数量 | mysqld_exporter | > 10/分钟 警告 |
| InnoDB 缓冲池使用率 | mysqld_exporter | > 90% 警告 |
| 主从复制延迟 | mysqld_exporter | > 5s 警告 |

#### 4.1.3 Redis 监控

| 指标 | 采集器 | 告警阈值（示例） |
|------|--------|-----------------|
| 内存使用率 | redis_exporter | > 85% 警告 |
| 内存使用量 | redis_exporter | > 配置 maxmemory 80% |
| 命中率 | redis_exporter | < 80% 警告 |
| 连接数 | redis_exporter | > 最大连接数 80% |

#### 4.1.4 Nginx / PHP-FPM 监控

| 指标 | 采集器 | 告警阈值（示例） |
|------|--------|-----------------|
| 请求速率 | nginx_exporter | QPS 突增 500% |
| 5xx 错误率 | nginx_exporter | > 1% 警告，> 5% 严重 |
| PHP-FPM 进程数 | php-fpm_exporter | > max_children 80% |
| PHP-FPM 请求队列 | php-fpm_exporter | > 10 警告 |

#### 4.1.5 应用层监控（ThinkPHP）

| 指标 | 采集器 | 说明 |
|------|--------|------|
| API 响应时间 | think-phpexporter / prometheus_client | P50/P90/P99 |
| API 错误率 | think-phpexporter | 5xx 比例 |
| 数据库查询时间 | think-phpexporter | 慢查询追踪 |
| JWT Token 刷新失败率 | think-phpexporter | 异常登录检测 |

### 4.2 Grafana Dashboard

| 大屏名称 | 内容 |
|---------|------|
| **系统总览大屏** | 核心指标聚合：CPU、内存、QPS、错误率、响应时间 |
| **MySQL 监控大屏** | QPS、连接数、查询缓存、慢查询、InnoDB 状态 |
| **Redis 监控大屏** | 内存、命中率、命令统计、持久化状态 |
| **Nginx 监控大屏** | 请求量、状态码分布、连接统计 |
| **告警历史大屏** | 告警记录、恢复时间、告警趋势 |

### 4.3 告警规则与分级

| 级别 | 名称 | 触发条件 | 通知方式 | 响应要求 |
|------|------|----------|----------|----------|
| P1 | **紧急** | 网站不可用、数据库连接失败 | 钉钉@所有人 + 电话 | 5 分钟内 |
| P2 | **严重** | CPU > 95%、MySQL 宕机 | 钉钉@值班人 | 15 分钟内 |
| P3 | **警告** | CPU > 80%、慢查询 > 10/分钟 | 企微消息 | 1 小时内 |
| P4 | **提示** | 磁盘 > 80%、连接数 > 70% | 邮件 | 工作时间 |

### 4.4 告警通知渠道

| 渠道 | 用途 | 配置方式 |
|------|------|----------|
| 钉钉机器人 | P1/P2 紧急告警 | Webhook URL |
| 企业微信 webhook | P3 警告 | Webhook URL |
| 邮件 | P4 提示 + 日报 | SMTP 配置 |
| Grafana 内置 | 测试阶段 | 界面配置 |

## 5. 部署方案

### 5.1 Docker Compose 部署

```yaml
prometheus:
  image: prom/prometheus:latest
  container_name: feiyu_prometheus
  volumes:
    - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml
    - ./prometheus/rules:/etc/prometheus/rules
    - prometheus_data:/prometheus
  command:
    - '--config.file=/etc/prometheus/prometheus.yml'
    - '--storage.tsdb.path=/prometheus'
    - '--web.console.libraries=/usr/share/prometheus/console_libraries'
    - '--web.console.templates=/usr/share/prometheus/consoles'
    - '--web.enable-lifecycle'
  ports:
    - "9090:9090"
  networks:
    - feiyu_network

grafana:
  image: grafana/grafana:latest
  container_name: feiyu_grafana
  environment:
    - GF_SECURITY_ADMIN_USER=admin
    - GF_SECURITY_ADMIN_PASSWORD=${GRAFANA_PASSWORD:-Admin@123}
    - GF_USERS_ALLOW_SIGN_UP=false
    - GF_SERVER_ROOT_URL=http://39.105.173.6:3000
  volumes:
    - grafana_data:/var/lib/grafana
    - ./grafana/provisioning:/etc/grafana/provisioning
  ports:
    - "3000:3000"
  depends_on:
    - prometheus
  networks:
    - feiyu_network

alertmanager:
  image: prom/alertmanager:latest
  container_name: feiyu_alertmanager
  volumes:
    - ./alertmanager/alertmanager.yml:/etc/alertmanager/alertmanager.yml
    - alertmanager_data:/alertmanager
  command:
    - '--config.file=/etc/alertmanager/alertmanager.yml'
    - '--storage.path=/alertmanager'
  ports:
    - "9093:9093"
  networks:
    - feiyu_network
```

### 5.2 Exporter 部署

```yaml
# node_exporter（服务器资源）
node_exporter:
  image: prom/node-exporter:latest
  container_name: feiyu_node_exporter
  command:
    - '--path.procfs=/host/proc'
    - '--path.sysfs=/host/sys'
    - '--path.rootfs=/rootfs'
    - '--collector.filesystem.mount-points-exclude=^/(sys|proc|dev|host|etc)($$|$)'
  volumes:
    - /proc:/host/proc:ro
    - /sys:/host/sys:ro
    - /:/rootfs:ro
  ports:
    - "9100:9100"
  networks:
    - feiyu_network

# mysqld_exporter（MySQL）
mysqld_exporter:
  image: prom/mysqld-exporter:latest
  container_name: feiyu_mysql_exporter
  environment:
    - DATA_SOURCE_NAME=root:proot123456@(mysql:3306)/
  ports:
    - "9104:9104"
  depends_on:
    - mysql
  networks:
    - feiyu_network

# redis_exporter
redis_exporter:
  image: oliver006/redis_exporter:latest
  container_name: feiyu_redis_exporter
  environment:
    - REDIS_ADDR=redis:6379
    - REDIS_PASSWORD=${REDIS_PASSWORD:-}
  ports:
    - "9121:9121"
  networks:
    - feiyu_network
```

### 5.3 Prometheus 配置

```yaml
# prometheus.yml
global:
  scrape_interval: 15s
  evaluation_interval: 15s

alerting:
  alertmanagers:
    - static_configs:
        - targets:
            - alertmanager:9093

rule_files:
  - "/etc/prometheus/rules/*.yml"

scrape_configs:
  # Prometheus 自身
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  # node_exporter（服务器）
  - job_name: 'node'
    static_configs:
      - targets: ['node_exporter:9100']

  # MySQL
  - job_name: 'mysql'
    static_configs:
      - targets: ['mysqld_exporter:9104']

  # Redis
  - job_name: 'redis'
    static_configs:
      - targets: ['redis_exporter:9121']

  # Nginx（可选）
  - job_name: 'nginx'
    static_configs:
      - targets: ['nginx_exporter:9113']
```

| 功能 | 说明 |
|------|------|
| 监控大盘 | Iframe 嵌入 Grafana 大屏（免登录） |
| 告警记录 | 查询历史告警列表 |
| 告警规则 | 可视化配置告警阈值（调用 Prometheus API） |
| 联系人管理 | 配置告警通知人和渠道 |

### 6.2 Grafana SSO 集成

通过 Keycloak（SSO 模块）实现 Grafana 免登录：

```yaml
# grafana.ini（provisioning/datasources/datasource.yml）
datasources:
  - name: Prometheus
    type: prometheus
    access: proxy
    url: http://prometheus:9090
    isDefault: true
```

```yaml
# grafana.ini（auth.generic_oauth）
[auth.generic_oauth]
enabled = true
client_id = grafana
client_secret = ${GRAFANA_CLIENT_SECRET}
scopes = openid profile email
auth_url = http://keycloak:8180/realms/feiyuadmin/protocol/openid-connect/auth
token_url = http://keycloak:8180/realms/feiyuadmin/protocol/openid-connect/token
```

## 8. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| Prometheus 存储瓶颈 | 时序数据丢失 | 设置数据保留策略（默认 15 天），外接对象存储 |
| 告警风暴 | 通知轰炸 | Alertmanager 收敛（group_wait、group_interval） |
| Exporter 影响业务 | 资源占用 | 独立容器部署，资源限制（CGroup） |
| Grafana 被爬取数据 | 安全风险 | 启用认证，IP 白名单 |
| 监控自身单点 | 盲区 | Prometheus 主备（Remote Write） |
