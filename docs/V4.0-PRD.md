## 3. V4.0 功能模块

### 3.1 AI Agent 智能助手 ⭐⭐⭐ P0

**一句话描述**：管理员能用自然语言完成任意后台操作（增删改查、生成报表、分析数据）。

#### 现状分析
- ✅ NL2SQL 接口已实现（`/pcapi/ai/nl2sql`），可将自然语言转换为 SQL
- ✅ execute 接口已实现，可执行 SQL 并返回结果
- ✅ tables 接口已实现，可获取数据表列表
- ❌ **Agent 能力缺失**——NL2SQL 只解决了"问"的问题，没有解决"做"的问题

#### 功能点

| 功能 | 描述 | 价值 |
|------|------|------|
| **自然语言 CRUD** | "帮我新建一个管理员，账号是 test，角色是运营" → 自动执行 | 零学习成本操作后台 |
| **多轮对话上下文** | 支持追问"把刚才那个用户的密码改成 123456" | 连续操作不中断 |
| **意图识别 + 分发** | AI 判断操作类型（增删改查/统计/导出），路由到不同 handler | 通用化扩展能力 |
| **执行结果确认** | 高危操作（删除/批量更新）先展示预览，确认后执行 | 安全可信赖 |
| **操作历史追溯** | 对话记录可保存、可复用、可导出 | 沉淀经验 |

#### 技术方案（简化版）

```
用户输入 → LLM 意图识别 → Action Router
                                    ├── 增删改查 → LowCode Engine → 执行
                                    ├── 统计分析 → NL2SQL → 执行 → 图表
                                    ├── 导出     → 生成文件 → 下载
                                    └── 兜底     → 搜索知识库 / 提示帮助
```

**LLM 选型待凯哥确认**（V3 遗留事项）

#### 验收标准
- [ ] 管理员输入"查询所有用户"，系统返回用户列表（NL2SQL）
- [ ] 管理员输入"新建一个管理员，账号：test"，系统预览 SQL，确认后执行成功
- [ ] 管理员追问"把他的状态改成禁用"，上下文保持
- [ ] 删除操作有二次确认

### 3.2 低代码建表 ✏️⭐⭐⭐ P0

**一句话描述**：不用写 SQL，用图形界面点点点就能创建数据表，然后自动生成 CRUD 页面。

#### 现状分析
- ✅ 后台已有"表单设计"模块路由（`/pcapi/ai/lowcode`）
- ✅ 数据库有 `sys_form` 表
- ❌ **建表功能未实现**——数据表还没建，lowcode 接口实际不可用
- ❌ **CRUD 页面生成未完成**

#### 功能点

| 功能 | 描述 | 价值 |
|------|------|------|
| **图形化建表** | 拖拽字段 → 设置类型/长度/校验 → 一键创建表 | 零 SQL 建表 |
| **字段类型丰富** | 文本/数字/日期/图片/富文本/外键/关联/关联记录 | 覆盖业务场景 |
| **自动生成 CRUD** | 建完表自动生成列表页/新增页/编辑页 | 开发效率提升 80% |
| **表关系管理** | 可视化维护表之间的关联关系（一对多/多对多） | 数据建模 |
| **预览 + 回退** | 可预览生成的代码，支持回退历史版本 | 安全可追溯 |

#### 验收标准
- [ ] 用户在图形界面创建"订单管理"表（含字段：订单号/金额/客户/状态/创建时间）
- [ ] 系统自动生成对应的列表页、新增页、编辑页
- [ ] 新生成的页面在后台菜单中可见且功能正常

---

### 3.3 工作流引擎 🔄⭐⭐ P1

**一句话描述**：拖拽式审批流设计器，支持条件分支、自动通知、审批节点。

#### V2.0 规划 vs V4 交付

| V2.0 规划 | V4 实际交付 |
|----------|------------|
| 可视化流程设计器 | ✅ 拖拽式 DAG 设计器 |
| 审批流 | ✅ 请假/报销/合同审批模板 |
| 条件分支 | ✅ 支持 if/else/switch 条件 |
| 会签/或签 | ✅ |
| 自动通知 | ✅ 站内消息 + 邮件通知 |
| 流程历史追溯 | ✅ 审批记录可查看 |

#### 验收标准
- [ ] 用户可在画布上拖拽节点，连接成审批流
- [ ] 支持条件分支（金额 > 10000 → 总监审批，else → 主管审批）
- [ ] 审批人收到站内消息通知
- [ ] 流程结束后可查看完整审批历史

---

### 3.4 数据大屏 📊⭐⭐ P1

**一句话描述**：拖拽式数据看板，支持折线图/柱状图/饼图/数字卡片，实时刷新。

#### 功能点

| 功能 | 描述 |
|------|------|
| **组件库** | 折线图、柱状图、饼图、数字翻牌器、地图、表格、轮播 |
| **拖拽布局** | 自由拖拽调整大小和位置 |
| **数据源绑定** | 绑定到某个 SQL 查询或 API 接口 |
| **自动刷新** | 支持定时刷新（5s/10s/30s/1min） |
| **大屏投影模式** | 全屏展示，左侧菜单隐藏 |

#### 验收标准
- [ ] 用户可从组件库拖拽"折线图"到画布
- [ ] 可绑定 SQL 数据源，图表实时渲染
- [ ] 支持投影模式（1920×1080 全屏）

---

### 3.5 定时任务可视化 ⏰⭐ P1

**一句话描述**：图形化配置 Crontab 表达式，可视化任务管理 + 执行日志。

#### 功能点

| 功能 | 描述 |
|------|------|
| **可视化 Cron 配置** | 下拉选择"每天 9 点"/"每小时"/"每周一"，不用手写表达式 |
| **任务模板** | 内置常用的定时任务模板（清理日志/备份数据/同步库存） |
| **执行日志** | 记录每次执行时间、耗时、结果 |
| **失败告警** | 任务失败后发送站内通知 |
| **手动触发** | 支持一键立即执行 |

#### 验收标准
- [ ] 用户可图形化配置"每天早上 9 点执行"（无需写 Cron 表达式）
- [ ] 任务执行后可在日志中查看执行结果

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| **性能** | AI 查询响应 < 3s（不含 LLM 网络延迟）；大屏图表渲染 < 500ms |
| **安全** | AI Agent 高危操作（DELETE/UPDATE）必须预览确认；工作流审批需操作权限 |
| **兼容性** | 适配 Chrome/Firefox/Safari；Element Plus 2.x |
| **可扩展** | AI Agent 支持后续接入更多 LLM（百度/阿里/腾讯混用）；工作流支持自定义节点 |
| **移动端** | 暂不开发 H5（按 v3 决策），但工作流审批支持移动端站内消息推送 |
