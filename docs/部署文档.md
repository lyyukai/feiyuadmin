# 飞羽管理后台 Docker 部署文档

## 📋 环境要求

### 最低配置
- **CPU**: 2 核
- **内存**: 4 GB
- **硬盘**: 20 GB
- **操作系统**: CentOS 7+ / Ubuntu 20.04+ / Debian 11+

### 软件要求
- **Docker**: 20.10+
- **Docker Compose**: 2.0+
- **Git**: (用于拉取代码)

## 🚀 快速开始

### 1. 进入项目目录

```bash
cd /www/wwwroot/feiyuadmin
```

### 2. 进入 Docker 配置目录

```bash
cd docker
```

### 3. 配置环境变量

创建 `.env` 文件：

```bash
cp .env.example .env
```

编辑 `.env` 文件：

```bash
# 数据库配置
MYSQL_ROOT_PASSWORD=root123456      # MySQL root 密码
MYSQL_DATABASE=feiyuadmin           # 数据库名
MYSQL_USER=feiyu                    # 数据库用户
MYSQL_PASSWORD=feiyu123456          # 数据库密码

# 端口配置 (可根据需要修改)
MYSQL_PORT=3306
NGINX_PORT=80
NGINX_SSL_PORT=443
PHP_PORT=9000
```

### 4. 构建并启动容器

```bash
# 构建并启动所有服务
docker-compose up -d --build

# 查看容器状态
docker-compose ps

# 查看容器日志
docker-compose logs -f
```

### 5. 安装 PHP 依赖

```bash
# 进入 PHP 容器
docker exec -it feiyu_php /bin/sh

# 安装依赖
composer install --no-dev

# 退出容器
exit
```

### 6. 配置 ThinkPHP

```bash
# 复制环境配置
docker exec -it feiyu_php cp .env.example .env

# 编辑数据库配置
docker exec -it feiyu_php vim .env
```

数据库配置示例：

```env
DB_CONNECTION=mysql
DB_HOST=mysql
DB_PORT=3306
DB_DATABASE=feiyuadmin
DB_USERNAME=feiyu
DB_PASSWORD=feiyu123456
```

### 7. 执行数据库迁移

```bash
docker exec -it feiyu_php php think migrate:run
```

### 8. 访问应用

打开浏览器访问：`http://your-server-ip`

## 🗄️ 数据库配置说明

### 默认数据库参数

| 参数 | 默认值 |
|------|--------|
| 主机 | mysql (容器内) / localhost:3306 (宿主机) |
| 数据库名 | feiyuadmin |
| 用户名 | feiyu |
| 密码 | feiyu123456 |
| 字符集 | utf8mb4_unicode_ci |

### 连接字符串 (ThinkPHP)

```env
mysql:host=mysql;port=3306;dbname=feiyuadmin;charset=utf8mb4
```

### 初始化 SQL

如需手动导入初始化 SQL，将 `.sql` 文件放入 `docker/mysql/init/` 目录，容器首次启动时会自动执行。

## 🔧 常用操作

### 启动服务
```bash
cd /www/wwwroot/feiyuadmin/docker
docker-compose start
```

### 停止服务
```bash
docker-compose stop
```

### 重启服务
```bash
docker-compose restart
```

### 重建服务
```bash
docker-compose down
docker-compose up -d --build
```

### 查看日志
```bash
# 所有服务日志
docker-compose logs -f

# 指定服务日志
docker-compose logs -f nginx
docker-compose logs -f php
docker-compose logs -f mysql
```

### 进入容器
```bash
# PHP 容器
docker exec -it feiyu_php /bin/sh

# MySQL 容器
docker exec -it feiyu_mysql /bin/sh

# Nginx 容器
docker exec -it feiyu_nginx /bin/sh
```

### 清理数据 (慎用)
```bash
# 删除所有容器和数据卷
docker-compose down -v

# 删除镜像
docker-compose down --rmi local
```

## 🔒 安全配置

### 修改默认密码

生产环境请务必修改默认密码：

```bash
# MySQL 密码
MYSQL_ROOT_PASSWORD=your_strong_root_password
MYSQL_PASSWORD=your_strong_password

# 同时更新 .env 文件中的数据库密码
```

### 配置 SSL (可选)

1. 将 SSL 证书放入 `docker/nginx/ssl/` 目录
2. 取消 Nginx 配置中 HTTPS server 块的注释
3. 修改证书路径

### 防火墙配置

```bash
# 开放端口
firewall-cmd --permanent --add-port=80/tcp
firewall-cmd --permanent --add-port=443/tcp

# 重新加载防火墙
firewall-cmd --reload
```

## ❓ 常见问题

### Q1: 容器启动失败

**检查 Docker 服务状态：**
```bash
systemctl status docker
```

**查看详细日志：**
```bash
docker-compose logs
```

### Q2: MySQL 连接失败

**检查 MySQL 是否正常运行：**
```bash
docker exec -it feiyu_mysql mysql -u root -p
```

**检查网络连接：**
```bash
docker exec -it feiyu_php ping mysql
```

### Q3: 权限问题

**文件权限：**
```bash
chown -R www-data:www-data /www/wwwroot/feiyuadmin
chmod -R 755 /www/wwwroot/feiyuadmin
```

### Q4: 端口冲突

如果 80 或 3306 端口被占用，修改 `.env` 中的端口映射：

```env
NGINX_PORT=8080
MYSQL_PORT=3307
```

### Q5: Composer 安装依赖失败

**切换镜像源：**
```bash
docker exec -it feiyu_php composer config -g repo.packagist composer https://packagist.phpcomposer.com
```

### Q6: ThinkPHP 路由 404

确保 Nginx 配置中的 URL 重写规则已启用，且 `.env` 中：

```env
URL_ROUTER_ON=true
URL_ROUTE_RULES=[]
```

### Q7: 上传文件失败

检查 storage 目录权限：
```bash
docker exec -it feiyu_php chown -R www-data:www-data /var/www/html/runtime
docker exec -it feiyu_php chmod -R 775 /var/www/html/runtime
```
