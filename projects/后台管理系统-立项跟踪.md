## 安装模块详细说明

### 文件清单

1. **`/www/wwwroot/feiyuadmin/backend/public/install.php`** - 安装向导入口
2. **`/www/wwwroot/feiyuadmin/backend/public/admin.php`** - 后台管理入口
3. **`/www/wwwroot/feiyuadmin/backend/public/install.lock`** - 安装锁定文件（安装后自动生成）

### 安装向导流程（4步）

| 步骤 | 页面 | 功能 |
|------|------|------|
| 1 | 环境检测 | 检测 PHP8+、PDO、fileinfo、curl、mbstring 扩展及目录权限 |
| 2 | 数据库配置 | 填写数据库连接信息（支持连接测试） |
| 3 | 管理员设置 | 创建首个管理员账号 |
| 4 | 安装完成 | 成功提示，进入后台 |

### 数据库写入

- **配置文件**: `/www/wwwroot/feiyuadmin/backend/config/database.php`
- **用户表**: `{prefix}user`（前缀可配置，默认 `sys_`）
- **密码加密**: MD5(盐值 + 密码)，盐值随机生成 32 位 hex 写入 `salt` 字段
- **安装锁定**: 成功后写入 `install.lock`，已安装状态直接显示锁定页面

### URL 访问

| 路径 | 说明 |
|------|------|
| `/install.php` | 安装向导 |
| `/admin.php` | 后台管理入口（未安装自动跳转安装向导） |
| `/admin/` | 前端静态资源（Vite build 输出目录） |
